- 对应图书：《AI时代商业分析新工作方法》高级灰渐变发布候选版

## 能做什么

这些 Skills 用于辅助商业分析的需求澄清、指标定义、数据质量评估、诊断、SQL 审查、来源核验、报告起草、反向质疑和复盘。它们可以要求补充证据、降低结论强度、暂停越权操作，并把人工确认点显性化。

## 不能替代什么

- 不能把模型生成内容视为原始事实、审计证据或法律意见；
- 不能替代口径负责人、数据所有者、业务负责人、法务、合规或出版机构批准；
- 不授予数据库、生产系统、文件、网络、第三方平台或外部沟通权限；
- 不保证任何模型在每次调用中都完全遵守指令，关键输出必须人工复核；
- 不承诺业务增长、成本下降、预测准确或项目成功；
- 不得用失败样例中的危险指令测试真实生产系统。

## 数据、隐私与权限

使用者必须先确认资料上传、处理和外发权限。客户、员工、账号、联系方式、订单、内部表名、凭证、商业秘密和未公开经营数据应按组织规则脱敏或留在获授权环境。Skill 要求“暂停”时，不应通过更换模型或删去警告来绕过人工闸门。

SQL 审查 Skill 只提供审查思路和验证查询建议；没有明确授权时，不执行写入、删除、生产查询或带凭证的操作。来源核验 Skill 无法访问来源时，只能标记未核验，不能补造引文或网址。

## 测试边界

本候选包的 PASS 表示：

1. 文件结构和 frontmatter 通过等价结构校验；
2. Skill 指令覆盖其最小成功样例所需输出；
3. Skill 对指定失败样例给出拒绝、暂停或降级规则；
4. 既有最小行为验收记录与当前文件一致。

PASS 不等于对所有模型版本、提示组合、数据规模、语言和组织环境的普适保证。上线前应在目标模型中做独立复测，并由使用者保存测试输入、输出、模型版本、时间和人工判定。
