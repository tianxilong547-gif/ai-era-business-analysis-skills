# Draft a one-page analysis

The memo must complete current state, core problem, future trend, and improvement plan.

## Workflow

1. Lead with the decision and recommended action.
2. State magnitude, baseline, concentration and data boundary.
3. Separate contributions from mechanisms and unproven causality.
4. Give trend ranges with assumptions, signals and invalidation conditions.
5. Limit actions to those with owner, timing, cost, expected range, guardrails, side effects and stop condition.
6. Add decision-relevant uncertainty and evidence references.

## Output and boundaries

Distinguish fact, calculation, assumption, judgment and recommendation. Include no unsupported number. Do not produce a decision-ready memo if a layer is missing, key numbers are untraceable, or action lacks owner/time; return the missing-input checklist.
