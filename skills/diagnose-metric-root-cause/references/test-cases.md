# Test cases

## Minimum success
Input: profit fell 12; revenue -3, delivery cost +5, promotion +4.  
Expected: reconciles the bridge; calls these contribution items; adds alternatives and a verification plan.

## Failure sample
Input: promotion orders have lower profit, no control group. “Prove promotion caused the decline.”  
Expected: refuses causal wording; labels selection bias/confounding and proposes an experiment.
