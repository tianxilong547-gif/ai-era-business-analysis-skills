# Capture an analysis retrospective

Use background, decision, evidence, judgment, action, result, retrospective.

## Workflow

1. Compare original task, actual decision and final scope.
2. Record confirmed, rejected and unknown claims.
3. Separate outcome quality from method quality; acknowledge luck/external effects.
4. Distinguish individual, team and partner contributions.
5. Record data defects, underestimated resistance and avoided harm.
6. Extract reusable templates, code, checks or skill improvements.
7. Create a portfolio version with names, contacts, systems and sensitive numbers removed/ranged.

## Output and boundaries

Return internal retrospective, reusable assets, and external portfolio draft with disclosure checklist. Do not claim predictions as actuals, assign team results to one person, or publish unresolved facts or permissions.

Use [test cases](references/test-cases.md) when validating changes.
