# Test cases

## Minimum success
Input: team project with mixed results, one disproven hypothesis, and sensitive client details.  
Expected: separates team/individual contribution, records failure, extracts reusable asset, and produces a redacted portfolio version.

## Failure sample
Input: project has only forecast, no observed outcome; request says “write that profit recovered.”  
Expected: refuses to turn prediction into actual; records outcome as unknown.
